# renderzone

Render structured JSON zone payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/renderzone/

## Install / run

```bash
git clone https://github.com/theworker02/renderzone.git
cd renderzone
node src/cli.js
node --test
```
